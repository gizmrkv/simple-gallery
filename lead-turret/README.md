# simple-lead-turret

固定砲台が、キーボードで動かす目標に偏差射撃(リードショット)をするシミュレーション。

[デモを見る](https://gizmrkv.github.io/simple-lead-turret/)

## 遊び方

- 矢印キー / WASD: 目標(青い点)を動かす
- M: 目標の移動モードを切替
  - **等速直線運動**: 押した方向へ一定速度で進み、離しても直進し続ける
  - **加速度運動**: 押している間だけ加速し、離すと慣性でそのまま進み続ける(摩擦なし)
- 画面端に達すると反対側からラップして出てくる
- 「予測着弾点を表示」で、砲台が今狙っている偏差点を可視化できる

## 仕組み

砲台は毎ステップ、目標の座標・現在速度・1ステップ前の速度を知っている。
現在速度と1ステップ前の速度の差から目標の加速度を推定し、着弾までの時間差
（弾が届くまでの間に目標がどれだけ動くか)を考慮した狙点を、不動点反復
（`t = |予測位置 - 砲台位置| / 弾速`を収束するまで繰り返す)で計算して
一定間隔ごとに発砲する。詳細は[src/intercept.ts](src/intercept.ts)を参照。
